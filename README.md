# ☕ Infinite Cozy Puzzle World

A relaxing, pressure-free puzzle game where every level you solve helps you build and decorate your own little world — a café, a bookshop, or a tiny town. No timers, no lives, no penalties. Just a gentle daily ritual.

![status](https://img.shields.io/badge/status-prototype-orange) ![platform](https://img.shields.io/badge/platform-web-blue) ![license](https://img.shields.io/badge/license-MIT-green)

## ✨ Features

- **Flow-style connect-the-dots puzzles** — procedurally generated, difficulty scales with level
- **Three cozy themes** — Café, Bookshop, and Tiny Town, each with unique decor pieces and NPCs
- **Persistent room editor** — drag, rotate, resize, and arrange every piece you unlock
- **Daily streak tracking** — no punishment for missing a day, just a gentle nudge to come back
- **Curated micro-narrative** — tone-safe story lines that react to your progress
- **Soft generative ambient audio** — built entirely with the Web Audio API, no audio files
- **Zero pressure design** — no energy system, no pay-to-continue walls, no fail states

## 🎮 How to Play

1. Choose a world theme — Café, Bookshop, or Tiny Town
2. Solve a puzzle by connecting matching colored dots without crossing paths
3. Unlock a piece of furniture, decor, or a visitor for your world
4. Arrange it however you like in your room
5. Come back anytime — there's no rush

## 🚀 Getting Started

This is a single-file, dependency-free web app.

```bash
git clone https://github.com/yourusername/infinite-cozy-puzzle-world.git
cd infinite-cozy-puzzle-world
```

Just open `index.html` in a browser — no build step, no npm install required.

For local development with live reload, you can use any static server, e.g.:

```bash
npx serve .
```
